# Intelligents - B2B Meetings Automation

A clean, refined flat minimalist design for a B2B meetings automation service.

## Design Philosophy

**Sophisticated intelligence, calm confidence, and future-focused clarity**

### Visual Language

- **Flat Minimalism**: No textures, gradients (minimal), or shadows
- **Generous White Space**: Breathing room between elements
- **Crisp Vector Forms**: Clean geometric shapes and smooth icons
- **Hierarchy Through Scale**: Clear visual structure using size and spacing

### Color Palette

#### Primary Colors
- **Navy** (`#0F172A`, `#1E293B`, `#334155`) - Authority and professionalism
- **Graphite** (`#18181B` to `#FAFAFA`) - Neutral foundation

#### Accent Colors
- **Azure/Cyan** (`#06B6D4`, `#0891B2`) - Technology and clarity
- **Lime** (`#84CC16`, `#65A30D`) - Energy and innovation highlight

#### Background
- **White** (`#FFFFFF`) - Main surface
- **Pale Gray** (`#FAFAFA`) - Subtle contrast

### Typography

**Primary Font**: Inter
- Modern, precise, and highly readable
- Excellent for both headings and body text
- Professional B2B aesthetic

**Scale**: Modular scale from 0.75rem to 3.75rem
**Weight**: 300 (Light), 400 (Regular), 500 (Medium), 600 (Semi-bold), 700 (Bold)

### Components

#### Icons & Visuals
- **SVG-based**: Scalable, crisp, and performant
- **Geometric Shapes**: Circles, rectangles, lines
- **Themes**: Collaboration, AI, scheduling, connectivity
- **Abstract Representations**: Flowing lines, network nodes, dashboard elements

#### Spacing System
Based on a consistent 0.25rem (4px) base unit:
- Micro: 4px, 8px, 12px
- Small: 16px, 20px, 24px
- Medium: 32px, 40px, 48px
- Large: 64px, 80px, 96px
- XL: 128px, 160px

### Sections

1. **Hero** - Bold statement with geometric visualization
2. **Features** - Grid of capabilities with abstract icons
3. **How It Works** - Linear process flow
4. **Stats** - Trust indicators with bold typography
5. **Pricing** - Clear tier comparison
6. **CTA** - Strong call to action
7. **Footer** - Organized information architecture

### Responsive Design

- **Desktop**: Multi-column layouts, spacious
- **Tablet**: Optimized grids, comfortable spacing
- **Mobile**: Single column, touch-friendly

### Technical Details

- **HTML5**: Semantic markup
- **CSS3**: Custom properties (CSS variables)
- **No Dependencies**: Pure HTML/CSS (no frameworks)
- **Performance**: Optimized for fast loading
- **Accessibility**: Semantic structure, proper contrast ratios

Simply open `index.html` in a modern web browser. No build process required.

## Browser Support

- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## Design Principles Applied

1. **Clarity Over Cleverness** - Direct communication
2. **Space as a Design Element** - White space creates focus
3. **Consistent Geometry** - Repeated shapes build recognition
4. **Purposeful Color** - Every color has meaning
5. **Hierarchy Through Typography** - Scale creates importance
6. **Simplicity Scales** - Works across all devices
